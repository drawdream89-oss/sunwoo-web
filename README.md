# sunwoo-web

선우특수소재 홈페이지(www.sunwoosm.com, 아임웹)의 공통 디자인·이미지·기능 파일.

| 파일 | 역할 | 아임웹 반영 |
|---|---|---|
| `sw.css` | 사이트 전체 디자인 (상단 메뉴 + 코드 페이지) | 올리면 자동 반영 |
| `sw.js` | 규격표 검색, 하단 '관리자' 링크 | 올리면 자동 반영 |
| `img/` | 코드 페이지 이미지 | 올리면 자동 반영 |
| `head.html` | 아임웹 Header Code (1회 붙여넣기) | 바꿀 일 거의 없음 |
| `pages/*.html` | 페이지별 글·표 (검색 노출용) | 내용 수정 시 해당 페이지만 다시 붙여넣기 |

불러오는 주소: `https://cdn.jsdelivr.net/gh/drawdream89-oss/sunwoo-web@main/…`
`main`에 올리면 GitHub Actions가 jsDelivr 캐시를 비웁니다.
